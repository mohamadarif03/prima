# PRIMA: Aturan untuk Antigravity

Seluruh aturan proyek ini ada di satu tempat agar tidak ada isi yang saling bertentangan:

@./AGENTS.md

Jika referensi di atas tidak terbaca, buka dan ikuti file `AGENTS.md` di root proyek, lalu baca `docs/prd.md` untuk detail produk.

## Tambahan khusus Antigravity

- Untuk tugas yang berkaitan dengan tampilan, jalankan aplikasi dan periksa hasilnya di browser sebelum menyatakan tugas selesai.
- Sebelum mengerjakan halaman, tampilkan rencana singkat (daftar komponen yang akan dibuat) lalu lanjutkan tanpa menunggu persetujuan, kecuali ada dependency baru.
- Jika aturan di file ini bertentangan dengan `AGENTS.md`, utamakan `AGENTS.md`.
